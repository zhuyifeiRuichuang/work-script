# 说明
在Linux环境离线部署任意版本JDK。

# JDK下载地址

Oracle JDK：[最新版本清单](https://www.oracle.com/cn/java/technologies/downloads/) ，[历史版本清单](https://www.oracle.com/cn/java/technologies/downloads/archive/)

OpenJDK：[版本清单](https://jdk.java.net/archive/)

# 部署JDK
下载JDK的`tar.gz`文件到脚本所在目录，例如`jdk-8u481-linux-x64.tar.gz`，执行脚本`bash deploy.sh`
