# 说明
docker环境里部署MySQL，实现数据持久化和配置持久便捷管理。
# 部署模式
单实例。在一个云主机部署一个MySQL server。  

# 备份数据
备份MySQL容器的数据。
## 方法1
备份数据可采用启动临时容器`backup-mysql`，将业务数据的数据卷挂载到`backup-mysql`的指定目录`/data1`，将物理机上存储备份数据的目录`/data/backup/mysql`挂载到`backup-mysql`的`/data2`，复制`/data1`到`/data2`，即可完成数据备份。数据卷在，数据在。数据卷不在时，物理机大多情况已经被破坏，无法抢救数据。
## 方法2
部署时，将容器的数据存放目录挂载到物理机的指定目录，在物理机配置crontab，定时复制目录内容到其他目录实现备份。此方法需信任物理机环境和物理机的使用者。

# 初始化数据库
`init-mysql.sh`用于初始化数据库，创建目录`sql`,将所有用到的sql文件放到里面。修改脚本的配置信息，填写MySQL容器的基础信息，填写期望创建的数据库和期望导入的sql文件，脚本会自动创建不存在的数据库，已存在的则会直接导入sql文件，会按照填写的顺序导入。
