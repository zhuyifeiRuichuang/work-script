# 说明

`init-data.sh`用于初始化数据库，自动创建数据库并导入sql文件。支持同一数据库按sql线后顺序导入sql文件。仅支持容器化部署的MySQL。需修改脚本的基础信息中的数据库连接信息，数据库名字和sql文件的名字。需将所有需导入的sql文件存放到当前目录下`sql`目录中。

数据库应当配置专用账户和访问权限，配置专用数据库及字符集等参数。

# 配置文件
