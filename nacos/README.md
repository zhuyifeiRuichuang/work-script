# 说明

记录nacos server部署和配置，用于生产环境的标准配置，可快速部署使用，可离线部署使用。 
容器镜像拉取失败时，可在网站`1ms.run`查看帮助手册。



| 目录 | 说明 |
|----|----|
| 单机模式 | 单实例，仅启动一个nacos实例，且部署在一台云主机中，适用于测试环境，存在单点故障风险。无专职运维的小业务规模生产环境。|
| 集群模式 | 适用于生产环境，高可用。需专职运维。当前主推部署模式。 |
| 多集群模式 | 适用于多数据中心。需专职运维。在多个nacos集群上套一层流量转发。 |
