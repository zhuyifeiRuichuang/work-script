## 关键踩坑：容器内改 /etc/hosts 不能用 sed -i
- K8s 的 `/etc/hosts` 是 kubelet bind mount，**`sed -i`（rename 覆盖）会失败**（Invalid cross-device link / Operation not permitted）。
- 脚本带 `set -e` 时 → 命令非零退出 → init 容器崩溃 → `Init:CrashLoopBackOff`。
- **正确写法**：用 `echo "..." >> /etc/hosts`（O_APPEND 写同一 inode，bind mount 允许）或 `cat tmp > /etc/hosts`（O_TRUNC，同样允许）；绝不 rename。
- `/etc/nsswitch.conf` 不是 bind mount，`sed -i` 可正常修改。
