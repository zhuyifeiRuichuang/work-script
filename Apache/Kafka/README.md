# 说明

官网`https://kafka.apache.org/`

基础知识`https://kafka.apache.org/intro/`

Kafka是一个event streaming 平台。

工作流程

1. 发布（写入）和订阅（读取）事件流，包括从其他系统持续导入/导出数据。
2. 持久可靠地存储事件流，存储时间长短随您所需。
3. 对正在发生的事件流进行处理，或进行回顾性处理。
