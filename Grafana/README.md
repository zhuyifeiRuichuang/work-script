# 说明

业界热门的数据可视化软件，可将Prometheus等软件抓取的数据可视化，需自定义面板配置展示的内容和样式。需配置数据源。

# 软件下载

建议用最新版本规避各类问题，

`https://grafana.com/grafana/download`

# 面板模板

面板用来图形化展示数据，可视化面板可参考模板，也可定制开发。

`https://grafana.com/grafana/dashboards/`

# 数据源采集

Grafana支持添加多种数据源用于可视化大屏展示。

参考：`https://grafana.com/docs/grafana/latest/datasources/`

# 部署

可根据部署环境选择不同目录下脚本。
