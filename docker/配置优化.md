# 说明

全新部署最新版Docker时，应做以下配置优化，使环境便于管理。

# 配置优化

暂停组件

```bash
systemctl stop docker
systemctl stop containerd
```

修改Docker的配置

```bash
cp /etc/docker/daemon.json /etc/docker/daemon.json.$(date +%Y%m%d)
vim /etc/docker/daemon.json
```

参考配置

```bash
{
  "registry-mirrors": [

    "max-size": "50m",
    "max-file": "3",
    "compress": "true"
  },
  "data-root": "/data/docker"

```



配置说明：

`data-root`配置为已经存在的目录，该目录必须挂载可动态扩展的大容量磁盘。

`registry-mirrors`是容器镜像在中国地区的加速。

`log`部分是日志存储优化，规避日志过大问题。



同步数据

```bash
rsync -av /var/lib/docker/ /data/docker/
```



新版Docker使用containerd作为runtime。

```bash
cp /etc/containerd/config.toml /etc/containerd/config.toml.$(date +%Y%m%d)
containerd config default | sudo tee /etc/containerd/config.toml
```



修改containerd配置文件

```bash
vim /etc/containerd/config.toml
```

重点配置，该目录必须挂载可动态扩展的大容量磁盘。

```bash
root = "/data/containerd"
```

同步数据

```bash
rsync -av /var/lib/containerd/ /data/containerd/
```

找到 `[plugins.'io.containerd.cri.v1.images'.registry]`

配置`config_path = '/etc/containerd/certs.d'`

`/etc/containerd/certs.d`下可以配置拉取镜像加速。

例如加速`docker.io`

```bash
# 创建目录
mkdir -p /etc/containerd/certs.d/docker.io
# 创建配置文件
vim /etc/containerd/certs.d/docker.io/hosts.toml

# 配置以下内容
# 此处是被加速的镜像来源地址
server = "https://registry-1.docker.io"
# 此处是加速地址
[host."https://docker.1ms.run"]
  capabilities = ["pull", "resolve"]
```



使配置生效

```bash
systemctl daemon-reload
systemctl start containerd
systemctl start docker
```



查询验证

```bash
containerd config dump | grep root
docker info | grep Root
# 拉取镜像测试
docker pull mysql
```
